# Design specification: Beyond Intelligence (black-and-gold treatment)
Canvas: 1080 × 1350 px, sRGB PNG. Margins 84 px left/right, ~96 px top, footer baseline 54 px from bottom.

Colour
| Role | Hex |
|---|---|
| Near black (slides 01, 04, 06, 09) | #0C0C0D |
| Midnight navy (03, 07) | #0F1420 |
| Warm ivory (02, 05, 08) | #EEE8DC |
| Ink on ivory | #141414 |
| Antique gold (labels, italic accents, bars) | #B4975A |
| Cool grey (secondary text) | #8B9099 |
| Caption grey | #6B6F77 |
| Electric blue: one use only (the lowest bar, "Evaluation 55%") | #4C7DFF |

Type: two families
- Instrument Serif (regular + italic): headlines, pull quotes, numbers. Cover 100 px; headlines 62–76 px; big-idea 104 px; statistic 180 px.
- DM Sans: body 30–33 px; labels 20 px semibold, uppercase, 0.2em tracking; captions 22 px; footer 20 px.
Photography: monochrome documentary/archival; colour images converted to black and white for a coherent carousel; no grain, vignettes or effects added.
Layouts: 01 cover band + headline · 02 offset photo + verb column · 03 three-object archival row · 04 full-width photo + question · 05 research bars · 06 asymmetric split · 07 two-photo diptych · 08 type only · 09 inset archival plate + closing question.
